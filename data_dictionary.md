| Field | Description |
| :--- | :--- |
| **CreditScore** | Numerical value representing customer creditworthiness. |
| **Geography** | The country of the customer (France, Germany, Spain). |
| **Tenure** | Number of years the customer has been with the bank. |
| **Balance** | Total amount of money in the account. |
| **IsActiveMember** | Binary indicator (1 = Active, 0 = Inactive). |
| **Exited** | The target variable (1 = Churned, 0 = Retained). |
